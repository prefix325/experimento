# Governed literature registry

This directory stores literature discovery and evidence records governed by VERSA. Consensus is one read-only discovery and paper-record provider; it is not a persona, full-text authority, or automatic source of accepted evidence.

- `queries/`: sanitized public or anonymized academic queries, filters, budgets, returned ids, and fetched ids.
- `records/`: fetched paper records and bibliographic verification status.
- `evidence/`: claim-bound evidence classifications and precise locators when verified.
- `syntheses/`: reviews that reference exact query, paper, and evidence record ids.

A search-only result may not be cited as a Consensus record. A fetched record remains `PROVISIONAL`. Acceptance for a claim requires verified identity, legitimate full text, a precise locator, and the applicable academic gate. GitHub history is canonical.
