# Pesos de modelo não incluídos

Os pesos do modelo local foram deliberadamente excluídos por tamanho e segurança operacional. A licença aplicável foi preservada neste diretório; configuração, quantização e hashes esperados permanecem nos manifests e arquivos de configuração publicados.

Antes de qualquer reprodução, obtenha o artefato por canal autorizado e confirme seu hash. Este espelho não usa Git LFS e não contém binários de inferência.
