# Dados não incluídos

Este diretório contém apenas manifests, checksums e documentação leve. Datasets brutos, preparados, blind e normal-holdout foram deliberadamente excluídos do repositório público.

Use os manifests e checksums preservados para localizar e validar cópias autorizadas. Não substitua arquivos ausentes por dados reconstruídos sem registrar provenance e sem respeitar o freeze metodológico.
